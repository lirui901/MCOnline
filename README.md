# MCONLINE · 本地 Minecraft 网页版启动器

一个纯本地的版本选择页：打开 `index.html`，点一下就进入对应的 Minecraft 网页版。

**3 个版本 · 5 个单文件构建 · 完全离线。** 不需要联网、不需要本地服务器、不需要安装任何依赖。

---

## 快速开始

1. 让下面 6 个 HTML 文件保持在**同一个文件夹**里，文件名不要改。
2. 双击 `index.html`（或拖进浏览器打开）。
3. 选版本 → 点构建按钮 → 开始游戏。
4. 游戏中按浏览器返回键或 `Alt + ←` 回到启动器。

> 直接以 `file://` 打开就行，不需要 `python -m http.server`，也不需要任何构建工具。

## 版本对照

| 版本 | 文件 | 内核 | 大小 | 说明 |
| --- | --- | --- | --- | --- |
| 26.3 | `263.html` | WASM（zeus/master） | 74.5 MB | 最新内核，内联解码器专门适配 `file://` 直接打开；只有这一种构建 |
| 1.12.2 | `1122.html` | WASM-GC | 19.2 MB | 经典版的 WASM 构建，加载较快 |
| 1.12.2 | `1122JS.html` | JavaScript | 30.0 MB | 纯 JS 兼容构建，不依赖 WebAssembly GC |
| 1.8.8 | `188.html` | WASM-GC | 14.4 MB | EaglercraftX 1.8，最小的构建，加载最快 |
| 1.8.8 | `188JS.html` | JavaScript | 17.2 MB | 纯 JS 兼容构建，老设备 / 旧浏览器首选 |

> 内核分类依据各文件内部的 `<title>` 与源码：`1122.html` 实际是 WASM-GC 版，`1122JS.html` 才是 JavaScript 版。

## 启动器功能

- **内核筛选**：全部 / WASM·GC / JavaScript，按浏览器支持情况快速定位。
- **加载提示**：点击后先显示载入中的进度条，大文件会提示等待 10–30 秒。
- **记住上次启动**：用浏览器本地存储记录，下次打开可一键"再次启动"。
- **新标签页开关**：可让游戏在新标签页打开，保留启动器。
- **键盘操作**：`1` `2` `3` 选版本、`Enter` 启动、`F` 切换筛选、`Esc` 取消选中。
- **零外部依赖**：CSS、脚本、图标全部内联在 `index.html` 里；即使脚本被禁用，链接本身依然可以跳转。

```
├── index.html        # 启动器，唯一需要打开的入口
├── 263.html          # 26.3   WASM
├── 1122.html         # 1.12.2 WASM-GC
├── 1122JS.html       # 1.12.2 JavaScript
├── 188.html          # 1.8.8  WASM-GC
├── 188JS.html        # 1.8.8  JavaScript
├── README.md
└── .gitignore        # 排除 .workbuddy/ 等本地数据
```

`.workbuddy/` 是 WorkBuddy 的本地工作数据（会话记忆、工作日志），与网站运行无关，已在 `.gitignore` 中排除，不会上传。

## 常见问题

**打开后白屏或报错？**
优先换用同一版本的 JavaScript 构建。WASM-GC 构建需要支持 WebAssembly GC 的较新浏览器；另外请确认用的是 Chrome / Edge / Firefox 等现代浏览器。

**一直卡在加载？**
`263.html` 有 74.5 MB，首次解析可能需要 10–30 秒，属正常现象。请耐心等待，不要反复刷新。

**能把文件夹发给别人吗？**
可以，直接打包整个文件夹，保持上面的目录结构和文件名。只发 `index.html` 会因为找不到游戏文件而无法跳转。

**要提交到 Git / GitHub 吗？**
5 个客户端合计约 155 MB，其中 `263.html` 约 78 MB。GitHub 对超过 50 MB 的文件会给出警告、超过 100 MB 会拒绝，仓库体积也会明显偏大。如果不想提交游戏文件，可以启用 `.gitignore` 末尾的"可选"规则，并改用网盘、Release 附件或 Git LFS 单独分发。

## 说明

- 5 个客户端均为 Eaglercraft 单文件构建，脚本、样式、游戏资源与 WASM 已全部内联；文件内出现的 `eaglercraft.ir` 只是注释或页面超链接，不是运行时依赖。
- 本仓库只提供一个本地导航页，客户端来自 Eaglercraft 项目，请遵循其相应许可。
- 跳转全部使用相对路径，整个文件夹可以随意复制或移动。
